# 100 个高难度爬虫挑战靶场（本地可复现）

## 这是什么
为验证「万能爬虫工具」的极限能力，我们把 100 个真实反爬场景做成了**本地可控靶场**：
每个挑战 = 一个 HTTP 路由，机制与真实网站等价（JS 质询/滑块/OCR/字体/WASM/WebSocket/
Service Worker/加密/签名/Digest/RSA/OAuth/蜜罐/反调试……），但 100% 可自动复现、无需公网。

## 运行
```bash
# 1) 起靶场（可选，runner 会自动起）
python3 challenges/server.py          # http://127.0.0.1:8755

# 2) 全自动测试（起服务器 + 逐挑战攻克 + 比对期望 + 报告）
python3 tests/challenge_runner.py             # 全部
python3 tests/challenge_runner.py 1 3 12      # 指定编号
```
报告输出：`challenges/results.json`

## 诚实说明
- 商业验证码（极验/易盾/顶象/阿里/腾讯/reCAPTCHA/hCaptcha）用**机制等价的可控实现**，
  考验同款能力（JS 质询/拖拽/轨迹/OCR/签名），不依赖外部付费服务；
- 短信/IMAP/OAuth/mTLS/TCP 指纹等需要真实外部条件的，用**本地模拟服务**实现等价流程；
- 所有挑战自动可复现，测试结果见 `results.json`。
