📊 数据报告

爬完的 CSV → 可视化图表

粘贴爬取结果 CSV（或任意表格），自动生成可视化报告（概览/统计/分组对比/分布图）。

🙋 第一次用？1 分钟看懂怎么用（点开看）
三步完成一个爬虫任务：
① 在下面「一句话任务」框里，用大白话写下你要什么（比如：抓取某网站的商品名称和价格）。不会写就点「常见例子」选一个再改。
② 点「生成执行计划」→ AI 会先告诉你怎么做、需要准备什么 → 你点「确认无误，开始执行」。
③ 等着就行：如果需要登录/验证码，会弹出浏览器窗口，你手动完成一次，工具自动继续。跑完的结果在「导出文件」里（json/csv/xlsx）。

经常卡住？看这里：
  • 要求登录的网站 → 勾选「需要登录 / JS 渲染」；或点右上角「🍪 导入会话」（先在调试 Chrome 登录一次）
  • 遇到验证码/滑块 → 在弹出窗口里手动滑/点，完成后自动继续
  • 抓出 0 条 → 点「🤖 没跑出来？让 AI 帮你找原因」，按它的建议做
  • 被网站拦截（403/频繁）→ 手机开热点重试，或填代理
  • 抓的数据不对 → 改任务描述，把「要哪几列、翻几页」写得更具体，重新生成计划
01 / TASK

一句话任务

AI 自动理解任务、生成配置并运行，全程实时反馈。先出「计划」供你确认，再真正执行。
⚙️ 高级选项（代理 / 定时 / Cookie / 并发 — 一般不用动，小白可直接跳过）
获取 Cookie 教程（Mac · 详细防错步骤） 
方法一（推荐·最不会错）：复制为 cURL
① 用 Chrome/Safari 打开目标网站并【登录】
② 打开开发者工具：Chrome 按 ⌥⌘I；Safari 先 设置(⌘,)→高级→勾选“显示网页开发者功能”，再 开发→显示网页检查器
③ 点「Network/网络」→ 按 ⌘R 刷新
④ 右键【任意请求】→「复制为 cURL / Copy as cURL」
⑤ 在复制内容里找 -H 'Cookie: ...'，把 ... 那串（名字=值; 名字=值; ...）粘贴到上面的框

方法二：从请求头复制
① 同上打开 Network → 点请求 →「Headers/标头」
② 找「Request Headers/请求标头」里的 Cookie: 行
③ 点击 Cookie: 后面的值（变可选中）→ ⌘A 全选 → ⌘C 复制

五个常见错误
① 从「存储/Cookie」面板复制 → 每行没有等号，格式不对（正确：名字=值; 名字=值; ...）
② 把 "Cookie:" 这几个字也复制了 → 只复制等号后面的值
③ 没登录就复制 → 必须先登录，Cookie 才有效
④ 复制到跨域请求（没有 Cookie 头）→ 换一个有 Cookie 的请求
⑤ 测试显示“被重定向验证中心” → Cookie 过期或 IP 被风控：重新复制 / 切手机热点

粘贴后点「测试 Cookie」，显示 ✅ 就说明可用。
先让 AI 生成「任务理解 + 技术路线」，你确认后才会真正开始抓取。

04 / AI

🤖 AI 配置（自己定模型）

分享给别人时，对方在这里填自己的 AI
万能爬虫工具的「大脑」就是 AI（负责理解任务/生成配置/诊断失败）。默认走你本机配置的模型；改成你自己的任意 OpenAI 兼容接口即可（DeepSeek / 千问 / GPT / 本地 Ollama 都行）。
💡 模型/接口/Key 保存后立刻生效，下次任务就用新 AI。Key 只存在本机配置文件里，界面显示脱敏。
04 / SHARE

📤 分享给其他人

同一网络下即可
默认只在本机访问。要分享：重启工具时加 --share，对方在浏览器打开你的「局域网地址 + 访问令牌」就能用（不需要装任何东西）。对方第一次用时在「⚙️ 设置」里填自己的 AI 即可。
⚠️ AI 配置是这台机器全局的：任何人修改都会影响这台机器上的所有任务。建议只由管理员（你）配置；分享给别人时，对方直接用默认 AI 即可。
