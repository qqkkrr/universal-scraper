❓ 获取 Cookie 教程（Mac · 详细防错）
① 方法一（推荐·最不会错）：复制为 cURL
   1) 用 Chrome/Safari 打开目标网站并【登录】
   2) 打开开发者工具：Chrome 按 ⌥⌘I；Safari 先 设置(⌘,)→高级→勾选"显示网页开发者功能"，再 开发→显示网页检查器
   3) 点「Network/网络」→ 按 ⌘R 刷新
   4) 右键【任意请求】→「复制为 cURL / Copy as cURL」
   5) 在复制内容里找 -H 'Cookie: ...'，把 ... 那串（名字=值; 名字=值; ...）粘贴到上面的框
② 方法二：从请求头复制
   1) 同上打开 Network → 点请求 → 「Headers/标头」
   2) 找「Request Headers/请求标头」里的 Cookie: 行
   3) 点击 Cookie: 后面的值（变可选中）→ ⌘A 全选 → ⌘C 复制
⚠️ 五个常见错误
   ① 从「存储/Cookie」面板复制 → 那里每行没有等号，格式不对（正确：名字=值; 名字=值; ...）
   ② 把 "Cookie:" 这几个字也复制了 → 只复制等号后面的值
   ③ 没登录就复制 → 必须先登录，Cookie 才有效
   ④ 复制到跨域请求（没有 Cookie 头）→ 换一个有 Cookie 的请求
   ⑤ 测试显示"被重定向验证中心" → Cookie 过期或 IP 被风控：重新复制 / 切手机热点
💡 粘贴后点下方「🧪 测试」，显示 ✅ 就说明可用
