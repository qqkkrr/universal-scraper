## 纪律层（每次任务都适用）

### 强制规则（铁律）
1. **公开数据、公开拿**：先判型再动手；能纯 HTTP 不上浏览器；robots/限速/预算闸默认开启。
2. **样本确认是阻塞门槛**：全量采集前必须先抓 3–5 条样本给需求方过目（自主模式且已有
   验收标准时可自检后继续）；**数据型任务用替代验证三件套**（官方解读数值对照 +
   随机点重抓一致 + 字段完整率——"源站不提供/本就为空"的字段先
   `verify --expect-empty "字段A,字段B"` 声明，不计缺口）；对账型任务用
   「源站声明计数 vs 实采」防"采到一半以为完了"。
3. **任务书量化规模 = 预授权**：任务书里写明的请求量按已授权执行，不逐条请示。
4. **评论型规模先估算报量**：笔记×(1+⌈评论/10⌉+展开回复)，深评论×5，导航间隔 ≥3–5s。
5. **登录前先验出口**：换网络先确认出口 IP；Chrome 无视 `--proxy-server`，代理必须
   库级注入（patchright）。
6. **不编数据、负结果如实报**：采不到就写采不到及原因；宁空勿错（字段无法确证就留空）。
7. **先查表再试错**（2026-10 快手战役反馈）：动手探测**任何子接口**（回复/楼中楼/搜索/
   收藏夹/二级列表）前，先查三处——站配方（recipes.md 的 R 编号）、判型表与
   `anti-block-playbook.md` 第九章（接口形态：GraphQL/protobuf-gRPC/WebSocket）、
   `sites` 命令的端点级登录标注（如 `评论=免登录 / 用户微博=需 Cookie`）。
   配方写"已下架/不存在"的直接跳过（别浪费轮次实测确认）；写"免登录"的不要先登录。

### 五幕流程（纪律骨架）
① **听懂需求**（字段/规模/验收标准/日期口径——先跑日期合法性预检：任务日期已过
或未开放=整单返工）→ ② **侦察 30 秒判型**（查判型表对号入座，不猜）→
③ **样本确认**（阻塞门槛）→ ④ **全量采集**（断点续跑/熔断退避；大批量先算
**磁盘账**：PDF 等重资产按"即采即弃+文本档案"模式——文本即充分统计量，
换词典可零成本重算）→ ⑤ **交付验收**（见下）。

### 交付验收（出口审计，四轮科研级深检沉淀）
交付前逐项过检；**检查按"字段 × 质量维度"矩阵推进**，每轮扩新维度，不是重复跑同一电池：

- **逐字回源**：每条文本回原文全量比对（不是抽样）；
- **文档内唯一性**：页眉/页脚也是原文——"回源全中"≠无重复伪影；
- **口径可复现**：freq/计数类字段必须单管线可重算（freq 公式自洽 ≠ 跨提取管线一致；
  多批次合并的面板必须统一提取管线并实测互算）；
- **面板窗口**：清单 first_year 与 last_year **双边过滤**（只滤一边会混入越界行）；
- **引用有效**：来源 URL 逐条在线可达；**审计/采集 UA 必须一致**（自标识 UA 会触发
  按 UA 封锁的站点）；根路径 URL 不算引用——找不到深链就显式标"来源深链待补"；
- **引用-声明对齐**：事件描述不得超过来源页实际支撑的事实，超出即收窄描述；
- **文档-数据一致**：说明页里写的每个数字都要与实际数据核对；日期字段先统一语义
  （报告年度≠发布年度：年报 FY Y 发布在 Y+1，修订版在 Y+2）；
- **合并必须整表重建**：写回式逐格回写会在表尾造幻影行、`rows.index` 对重复行恒返
  首位导致错位；提取结果必须带键（如 stkcd+date），按位置 zip 拼接在行数变化后整体错位；
- **静默失败即红旗**：API 参数缺失静默返回 0 条（如巨潮 stock 缺 orgId）、
  PDF 文本层损坏输出乱码——都要主动探测，不能假设"没报错=没问题"。

### 合规红线
仅用于合法合规用途；不绕付费墙、不碰个人隐私数据、不伪造身份；目标站服务条款
与当地法规优先；产物中的登录态（cookies/browser profile）永不外发。

## 与 Full 版的分工
